# T1: timestamped note transcripts

## Implemented

- Note detail uses individual stored sentences when a majority have valid segment timing (0–30 seconds). A 0/0 legacy body, a coarse whole-note span, and bodies without useful timing retain the existing plain text rendering. No engine or stored transcript writer changed.
- Timestamps seek the shared note player, including the saved-note sheet. The player's own time updates drive the active row. Wheel, touch, keyboard scrolling, and text selection suspend follow; **Follow playback** restores it.
- Plain Copy remains. Timed transcripts add **Copy with timestamps** (`[mm:ss]`, with hours when needed) and Markdown export. The export uses the share sheet on phones where available and a file download elsewhere.
- Stored speaker names are shown on speaker changes when more than one speaker exists. Existing Me/Them names from stereo notes and Speaker 1/2 names from diarization flow through without relabeling mono notes.

## Reviewer follow-up

- The signed-out/offline device note now supplies the timestamped copy callback. The menu hides that action for any caller without a handler. A mounted device-note test clicks it and verifies the clipboard text.
- Valid segment starts are indexed once. Playback uses binary search; a stable row tree and row-specific subscriptions update only the previous and current active rows. A 2,000-row test checks repeated clock ticks render no unchanged rows.
- Timestamp buttons have padded 44 × 44 px targets for coarse pointers; fine-pointer layout keeps its previous density. The production CSS build contains the pointer media rule.

## Overlaps and limits

- **A1:** `NoteDetailView.tsx` and `NoteDetail.tsx` are shared surfaces; this slice changes the Transcript section and its copy wiring only. A1 must reconcile its note status changes here.
- **#350:** the same transcript speaker names and saved-note player surface are touched. This slice reads the labels already stored; #350's channel production and stereo playback remain its own work.
- Timed engine output with a single span over 30 seconds stays plain until T2 supplies shorter grounded segments. Splitting it now would invent seek times. The actual Mac and phone UI and native share sheet have not been exercised on devices.
