# U1 · Mac main thread off-limits

The eleven disk-touching recorder/file Tauri commands are async and run their original synchronous bodies in `spawn_blocking`. The two remaining synchronous recorder commands (`recorder_status`, `recorder_models_progress`) are async as well, so the source guard rejects any future synchronous recorder command. Stop's `import_finished_segment` and its possible WAV encode run on a blocking worker. Retry and recovery run their entire disk and encode paths there. Whisper timeout now calls `stopTranscription` before reporting failure.

Verification: a Rust source guard covers every `#[tauri::command]` under `recorder/`, and a fixture WAV test checks that the actual recovery encode path runs on another thread. See `validation/exo-u1-instruments.md` for the human 250 ms Hang Detection procedure and the unmeasured end-to-end criterion. Desktop adapter TS tests and typecheck are part of the validation run.

Verified in-flight overlaps: #350 also touches `desktop/src-tauri/src/recorder/engine.rs`, `files.rs`, and `extras.rs`; U1 changes only command/thread boundaries in those files and leaves `desktop/local-transcription/src/audio_import.rs` and stereo processing untouched. #348 overlaps `engine.rs`; #351 overlaps `extras.rs`. Merge coordination is needed for these files.
