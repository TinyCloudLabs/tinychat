# U1 · Mac main thread off-limits

The eleven disk-touching recorder/file Tauri commands are async and run their original synchronous bodies in `spawn_blocking`. The two remaining synchronous recorder commands (`recorder_status`, `recorder_models_progress`) are async as well, so the source guard rejects any future synchronous recorder command. Stop's `import_finished_segment` and its possible WAV encode run on a blocking worker. Retry and recovery run their entire disk and encode paths there. Whisper timeout now calls `stopTranscription` before reporting failure.

Verification: a Rust source guard covers every `#[tauri::command]` under `recorder/`, and a fixture WAV test checks that the actual recovery encode path runs on another thread.
