# U2 · Instant Mac Stop

Based on U1 #365 at `75d917ef` (including its `1ae8f456` import lock fix). This PR targets `main` and merges after #365.

Stop returns a preparing note and enables Done after native source audio and
the per-note stopped journal are fsynced. Encoding/import runs in the
background through U1's `IMPORT_LOCK` and unique import temp paths. The note's
shared `ledger.localAudio` state is `preparing`, `ready`, or `failed`; A1 can
project this state. Playback, chunk reads, metadata, upload, and transcription
wait until ready. A failed finish retains the source and offers typed retry.
New capture can start while the older note finishes: stopped-source retention
and stop-journal publication do not wait on `IMPORT_LOCK`. Only encode/import
and shared import/failure writes take it. Window close, Cmd+Q, and app-menu
Quit share the specified single Quit/Wait prompt; relaunch imports the same
stopped note. A deleted note clears its stopped source before recovery can
import it. A completed upstream MP3 is used directly; only an interrupted
encode uses the retained WAV.

The pinned anarlog stop call returns before WAV finalization and provides no
pre-encode durability signal. The vendored `listener-core` now publishes a
fsynced marker after all WAV writers are finalized and fsynced, before MP3
encoding. Exo requires that marker and retains the WAV through a hard link.
This is an explicit upstream boundary change, documented in its provenance.

Verification:

- Desktop adapter, receipt, quit prompt: 72 tests passed. Includes simulated
  kill after receipt/relaunch producing one complete note, source/journal
  durability gate, blocked readers, empty final audio, deletion during finish,
  Whisper resume, app-menu Quit, capture during finishing, and typed retry.
- Recorder Rust tests: 35 passed, including sparse 1 min, 30 min, and 3 h
  source fixtures. The latest native retain+fsync run measured 26, 26, and
  28 ms.
- Fake bridge stop-to-local-commit timings: 0.2–0.6 ms across the 1 min,
  30 min, and 3 h durations. These measure adapter overhead only.
- `cargo check --features transcription` and frontend `tsc --noEmit` passed.

Unverified: an end-to-end physical Mac Stop ≤1 s for real 1 min, 30 min, and
3 h recordings; the fixture timings exclude upstream writer drain and actual
storage latency. A real process kill/power-loss test has not run. The source
boundary and receipt logic are tested with deterministic fixtures, not a
microphone or speakers, as the common brief requires.
The vendored crate's standalone marker test was not verified: its separate
workspace resolved an incompatible `specta` version in a transitive anarlog
dev dependency. The desktop build and recorder suite compile the vendored
production crate and pass.
