Problem and resulting behavior

A find → read → synthesize request can exhaust its ordinary rounds before an invalid citation draft gets a repair. Raw version-2 tool results can also lose their useful evidence under the generic head-only context cap. This PR projects cited summaries, actions, and excerpts into bounded valid JSON with source references and coverage metadata before that cap, then allows one clean citation repair when needed.

The citation gate expands a shortened token only when it uniquely identifies a supplied citation, then requires every recognized closed uppercase [M…]/[T…] token to be supplied. Invalid drafts remain hidden; a failed repair uses the existing safe fallback. Public-web and ordinary streaming, accounting, completion identity, and cancellation retain their existing paths.

Simple, unambiguous last-week summary requests derive the previous Monday–Sunday interval from the browser's trusted local date and timezone. Discovery arguments are normalized before recording and dispatch, and the same scope reaches clean synthesis and citation repair. Explicit dates, selected reads, and unsupported or ambiguous phrasing retain existing behavior. The matcher is intentionally conservative.

Validated participants and organizer email are retained when they fit. Budget pressure omits whole names or addresses, records omission counts/flags and a metadata-budget reason, and marks coverage limited. This avoids presenting a shortened identity as a complete value.

Final and repair guidance instruct the model to disclose partial/truncated evidence and distinguish matched meetings from complete transcript coverage. Citation membership remains a syntax check, not an independent factual audit.

Known remaining issues

  • Ordinal context: GLM-5.2 correctly resolved and read the second displayed meeting, but clean synthesis received only the current question and current-turn results. It then treated a single-meeting result as lacking a second meeting. Kimi rediscovered the full list before its target read and completed the summary. Preserve the parent answer or resolved ordinal identity through synthesis/repair; narrow the blanket instruction to omit a reference for room follow-ups.
  • Qwen request format: the route prepends its own system guidance to existing browser system context. Synthetic requests with the same tool schemas reproduced provider 400 for two consecutive system messages: System message must be at the beginning. Combining the same synthetic content into one system message returned 200. Successful probe streams were cancelled at headers; this establishes request admission, not a repaired browser flow. No fix is included for this incompatibility.
  • Availability and latency: GLM-5.3's provider returned 503 before tools, including one retry. Provider reasoning time and intermittent transcript-service failures remain material; they are distinct from selection or citation failures.
  • Evidence limits: the legacy gate does not validate every claim, intended target, or completeness assertion. Citation labels may repeat across separate tool results, and the conservative date matcher is not a general natural-language parser.
