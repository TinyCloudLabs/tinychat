Platform marks shown beside an agent's name in the Home feed (frontend/src/feed/AgentMark.tsx).

Each file is copied unchanged from Simple Icons (https://github.com/simple-icons/simple-icons),
icons/<name>.svg at commit cd796c98565fc466923fc1128b962e133fa3c612. Simple Icons is released under
CC0-1.0; its data file lists no other licence for these five icons. Each mark is a trademark of its
owner and is shown only to say which platform an agent runs on. Check each owner's brand rules
before Home shows them publicly.

claude.svg      Simple Icons "Claude" (Anthropic)            source listed: https://claude.ai
gemini.svg      Simple Icons "Google Gemini" (Google)        source listed: https://gemini.google.com
cursor.svg      Simple Icons "Cursor" (Anysphere)            source listed: https://cursor.com/brand
perplexity.svg  Simple Icons "Perplexity" (Perplexity AI)    source listed: https://www.perplexity.ai
opencode.svg    Simple Icons "OpenCode"                      source listed: https://github.com/anomalyco/opencode (packages/identity/mark.svg)

No file could be included for ChatGPT, Codex, Grok, Meta Muse, OpenClaw or Hermes: Simple Icons has
none for them (OpenAI's and xAI's marks are not in it), and their brand pages could not be reached
from here. Those platforms show their name without a mark.
