New setting on the Mac: Offer to record when a call starts, the first row of Meetings in Capture settings. It is on by default. When a call starts, a small tile offers to record it: Start begins a recording, Not now closes the tile for that call. The tile is its own small page (call-prompt.html), so it does not load the app. The setting stays hidden until the desktop app supports it. Nothing changes on the web or on phones.
