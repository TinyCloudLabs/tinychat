In a chat that has used your data or content from other sites (a search, a meeting transcript, pasted text, or a saved memory written from such a chat), an image in a reply asks first: it shows the full address and a Load button, and loads one address at a time. Chats that have used none of these load images as before. Images in notes do not load when a note opens: each shows its description and site, with "Load images from <site>?" and an Allow button for that site. A link shows its full site name next to its text.
