Read the full setup instructions

  1. Paste the prompt into your agent.

    It installs the TinyCloud CLI and skills once. Local OpenCode 1.18.31 on macOS loads its sign-in adapter automatically, without a restart. Start an empty terminal chat with Node.js 22.20 or later available.

  2. Sign in and approve access.

    In OpenCode, complete sign-in in the browser, then paste the code into the conversation. Your agent verifies it automatically. Your app’s connection settings are already included.

  3. Ask about your last meeting.

    Your agent reads the selected meeting and answers with source references. You can return with saved valid access or export a local session handoff.

What this release can read

Reads the supported synced meeting catalog and its transcript or generated-notes bodies. KV-only records and meetings still held only by the backend are outside this release's discovery scope. Partial searches and reads remain explicit. Coverage and permission details.
